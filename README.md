# 씨엔브이텍 온라인 판매 CRM (crm-tonoi)

씨엔브이텍(주) 온라인 판매 고객 관리 웹앱입니다. 기존 온라인판매대장(고객 423명·판매 446건)을
내장 데이터베이스로 불러와, 고객별 구매·상담·반품/교환·AS 이력을 한 곳에서 관리합니다.

## 구성
- `index.html` — CRM 웹앱 (단일 파일). 브라우저에서 바로 실행되며, 데이터는 팀 공유 저장소에 보관됩니다.
- `docs/supabase-migration.md` — 정식 서버(Supabase) · 로그인 · 다중사용자 전환 설계서.

## 주요 기능
- 이름·연락처·시리얼·구매처 통합검색
- 고객 상세 타임라인(구매 / 상담 / 반품·교환 / AS)
- 반품·교환 상태관리 및 사유 검토 화면
- 시리얼 기반 AS/보증 조회 (보증기간 자동 계산)
- 다품목 확장, 엑셀·JSON 백업/복원

## 다음 단계 (Supabase 연동)
`docs/supabase-migration.md`의 스키마와 절차에 따라 저장소를 Supabase(관리형 PostgreSQL + 로그인 + 권한)로
전환하면, 실제 로그인·권한·다중사용자 운영이 가능합니다.
